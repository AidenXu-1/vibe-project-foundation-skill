# 路线图

已有结论的开工阶段可合并。当前做到哪一步见[当前工作说明](progress.md)。

| 里程碑 | 做完的标志 |
| --- | --- |
| M0 地基 | 从本地版本能取回项目文件、本次需求与进度。 |
| M1 需求草案 | 写明谁遇到什么问题，以及第一版怎样算有用。 |
| M2 风险检查 | 找到最可能改变方案的问题。必要时先用样本、原型或小实验验证，将结论写入需求或决策记录。 |
| M3 首版范围 | [首版范围](spec.md#4-mvp-范围)、技术路线和验收标准已定。 |
| M4 工程启动 | 在 `app/` 建立工程，按[运行说明](../app/README.md)能启动或通过最小验证。 |
| M5 功能开发 | 先从实际入口演示用户最需要的一件事，再逐项开发和验证。 |
| M6 维护 | 按影响范围改进产品，复验受影响的旧行为。 |
